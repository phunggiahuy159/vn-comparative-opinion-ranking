(slides dated 2021-09, Vietnamese). `slides/` = original PDFs, `text/` = extracted text (searchable with grep).

| Deck | Topics (useful for citing course methods in reports) |
|---|---|
| L01-Intro | WWW, data mining process (KDD: clean → integrate → select → transform → mine → evaluate → present), web mining types |
| L02-MachineLearning-01 | Evaluation methods, decision tree, Naive Bayes, SVM, kNN |
| L02-MachineLearning-02 | Feed-forward NN, CNN, RNN, ensembles |
| L02-MachineLearning-03 | Clustering: k-means, hierarchical, distance functions, evaluation, LU/PU learning |
| L03-Data-visualization | Static charts, pixel-based, vector-space viz, hyperbolic trees, SOM |
| L04-Information-retrieval | IR models, relevance feedback, evaluation, text preprocessing, inverted index, LSI, web search, meta-search, web spam |
| L05-LinkAnalysis-01/02 | Graph ranking (PageRank/HITS), community detection, link prediction, node classification |
| L06-OpinionMining-01 | Opinion mining tasks, unsupervised & supervised sentiment classification |
| L06-OpinionMining-02 | Aspect extraction, aspect-level sentiment classification |
| L06-OpinionMining-03 | Entity detection/assignment, comparative opinions, opinion spam |
| L07-InformationExtraction | IE architecture, NER, unsupervised relation extraction, distant supervision, coreference |
| L08-RecommendationSystems | Evaluation, kNN CF, matrix factorization, NCF, session-based recommendation |
| L09-OnlineAd-QueryMining | Online/search advertising, query mining |
